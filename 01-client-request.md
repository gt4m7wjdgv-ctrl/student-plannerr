# 01 - Client Request

## Client Information
Client role: University student

## Client Request (in the Client's Own Words)

I want a simple system that helps me organize my university activities. I sometimes forget assignment deadlines or exam dates, and it is hard for me to keep my class schedule and study plans organized.

I would like to enter my weekly class timetable and make a plan for studying each day. I also want to write down my assignments and projects, set a deadline for each one, and record my exam dates.

It would be helpful if I could see which tasks I have completed and which ones are still pending. I want to check my upcoming activities in one place instead of using several notebooks or applications.

The system should be easy to use and understandable. I mainly need a useful tool for managing my student life.

## Client's Main Needs

- Organize weekly class schedules.
- Plan daily study activities.
- Record assignments and projects.
- Save exam dates and deadlines.
- Track completed and pending tasks.
- View upcoming academic activities easily.
