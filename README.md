# Student Planner and Management System

## Project Description
A simple system that helps students organize classes, study sessions, assignments, projects, and exam dates in one place.

## Problem Statement
Students often use separate notebooks, calendars, or applications to manage academic responsibilities. This can make it difficult to remember deadlines and balance study activities. This system provides one organized place to plan and track these tasks.

## Main Features
- Create and view a weekly class timetable
- Plan daily and weekly study sessions
- Add assignments and projects with due dates
- Record exam dates
- Track completed and pending tasks
- View upcoming academic activities

## Target Users
- University and college students
- Students who want to organize their study schedules and deadlines

## Proposed Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: Python
- Database: SQLite
